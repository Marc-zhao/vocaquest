// HOW IT WORKS

3 步开始闯关

01
获取邀请码

联系你的老师，获取专属学生邀请码。每个邀请码只能使用一次，确保班级安全。

02
注册并选择班级

输入真实姓名、邮箱、密码与邀请码，选择所在班级完成注册。班级选定后不可更改，请认真填写。

03
选词包，开始闯关！

老师已分配词包任务？直接进入地图开始闯关。也可加载自己的词包进行自由训练，积累 XP 冲上排行榜。

∞ 支持词包数量
5+ 文件格式支持
3 答题模式
0 需要安装的软件
